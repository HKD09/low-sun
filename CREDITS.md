## Sound effects

From Kenney (www.kenney.nl), "Impact Sounds" and "Interface Sounds" packs, licence CC0, copied from the sound library on this Mac:

`click`, `footstep_concrete`, `impactGeneric_light`, `impactGlass_light`, `impactMetal_heavy`, `impactMetal_light`, `impactMetal_medium`, `impactMining`, `impactPlate_heavy`, `impactPlate_light`, `impactPlate_medium`, `impactTin_medium`, `impactWood_medium`, `switch`, `toggle`.

Every other sound (the rifle and pistol, the drones, doors, valves, pumps, wind, drips, hum, reverbs) is synthesised in code at run time.

## Made for this project

- The station itself (level geometry, lightmaps baked in Blender 5.2 with Cycles), both drones, all decals and signs, all shaders, and all game code.
