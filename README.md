# LOW SUN

A short first-person shooter that runs in a browser tab. One place, two weapons, one mission of about ten minutes.

**Play:** open the game's page in Google Chrome on a laptop or desktop with a keyboard and mouse, wait for it to load (about 190 MB the first time), and click.

| Do this | With this |
| --- | --- |
| Move | `W` `A` `S` `D` |
| Look | Mouse |
| Fire | Left click |
| Aim | Hold right click |
| Reload | `R` |
| Run | Hold `Shift` |
| Jump | `Space` |
| Use a switch | `E` (hold `E` on a valve) |
| Swap rifle and pistol | `Q` |
| Record a clip | `V` |
| Pause, and settings | `Esc` |
